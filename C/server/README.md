#### Run the PHP Server


```--> output.php or server.php```

Use the built-in PHP server to serve your PHP script:
```sh
php -S localhost:8000
```

[NOTE]Open a web browser and navigate to http://localhost:8000/server.php to see the results.

This setup will run the vanilla_organizer program and display its output in a formatted HTML page. Ensure that the compiled C program (vanilla_organizer) is in the same directory as the PHP script for this to work correctly.
